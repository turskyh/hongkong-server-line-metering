## 便宜的差异，藏在三个地方

**线路。** 香港机房到国内三网的路由不统一。直连（CN2 GIA、CMI、AS4837、CUG 这类）延迟低、晚高峰相对稳；绕日本的线路便宜，延迟数字可能还行，但抖动明显。判断方法很简单：先看商家写的是不是三网直连，再找同款机型的实测路由图。

**流量计费方式。** 同样是 2 核 2G，一种给你高带宽但每月流量有限，用完限速；另一种带宽压到 5～10M，但流量不限。前者适合访问集中在白天的网站，后者适合长期挂着跑小流量的服务。买错这一步，比买贵更让人难受。

**附加项。** 独立 IP 普遍 5 元/个；硬盘超出标配要按天扩容；高防 IP、备份、快照都可能是额外收费项。这些加起来能让「20 元/月」变成「40 元/月」。

## 流量叠加型还是流量不限型

雨云官方计费文档写得很清楚，多数区域提供两种网络计费模式：

> 流量叠加型：带宽较高，按流量使用计费，支持流量包补充，适合流量波动较大、带宽需求较高的场景。
> 流量不限型：固定带宽计费，带宽较低，不单独计流量，适合流量稳定、持续使用的场景。

两个细节值得留意。套餐流量是按周期发放的，不是一次性给你；流量耗尽后进入限速状态，香港五区限速到 5Mbps，五区的流量包价格是 20 元/1TB，比二区的 1TB/200 元便宜一个数量级。

实际结论：如果你每个月流量消耗稳定且不大（比如日均几百访客的站点），不限流量款省心；如果流量集中在某些天爆发、平时几乎不动，或者你要跑下载、拉镜像，选流量型再按需买流量包更划算。

## 便宜不等于合适：几个场景判断

**适合的**：个人博客和静态站、外贸独立站和落地页、开发测试环境、API 中转和 AI 接口调用、大流量下载分发、轻量后台服务。

**要谨慎的**：

- 对国内访问延迟有硬要求的业务。香港五区线路偏国际，延迟 139ms 上下，别拿它当回国优化线路用。
- TikTok 运营。有测评明确记录五区解锁情况是 Netflix、Disney+、YouTube 可用，TikTok 不行。
- 需要发邮件的业务。测评里提到 SMTP 端口大多被封，SMTPS 部分可用。
- 要求原生 IP 的场景。香港三区这类 CN2 优化线路的机器是不提供原生 IP 的，做 SEO 或特定服务前先确认。

还有一个容易被忽略的点：便宜的入门配置不等于能直接上生产。1 核 1G 跑宝塔加 WordPress 会很快吃满内存，2 核 2G 是更现实的起步线。

## 常见问题

**香港服务器需要备案吗？**
不需要。网站部署在香港节点，只要内容合规就能直接解析上线，这是香港节点相比国内机房最主要的便利。

**月付 20 元档能跑 WordPress 吗？**
能跑，但建议从 2 核 2G 起步，再配合缓存插件和合理的 PHP-FPM 参数。1 核 1G 更适合测试机、监控脚本和静态页面。

**流量用完了会怎样？**
不会停机，会限速。香港五区限速到 5Mbps，可以买 20 元/1TB 的流量包恢复高速；二区的流量包是 200 元/1TB，选区域时可以把这个差价算进去。

**续费会涨价吗？**
套餐本身是月付定价，长期折扣（9 折 / 8 折 / 7 折）在续费时同样适用。但如果购买时叠了首月 5 折券，第二个月就会回到正常价，这点要提前算好。

**香港机器和国内机器怎么选？**
用户在国内且能接受备案，国内节点延迟更低；不想走备案、面向亚太或海外用户，香港节点更顺手。预算特别紧又必须服务国内用户，也可以对比宿迁、湖北十堰这类国内低配机型，价格更低，但需要备案或配置独立 IP。
